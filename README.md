# ონლაინ მაღაზია

ეს არის Next.js-ზე აწყობილი ონლაინ მაღაზიის სასწავლო პროექტი.

## გამოყენებული ტექნოლოგიები

- Next.js
- React
- Redux Toolkit
- React Hook Form
- Yup
- Fake Store API
- JSONPlaceholder API

## პროექტის ფუნქციები

- პროდუქტების ჩამონათვალის ნახვა
- პროდუქტის დეტალების ნახვა
- მომხმარებლის რეგისტრაციის ფორმა Yup ვალიდაციით
- ავტორიზაცია Fake Store API-ის საშუალებით
- „დამიმახსოვრე“ ფუნქცია, რომელიც ტოკენს `localStorage`-ში ინახავს
- კალათაში პროდუქტის დამატება
- კალათაში რაოდენობის გაზრდა და შემცირება
- პროდუქტის კალათიდან წაშლა
- კალათის საერთო რაოდენობისა და ფასის ნახვა Redux-ის საშუალებით
- პროფილის გვერდი

რეგისტრაციისთვის გამოყენებულია JSONPlaceholder-ის სატესტო API. ის მიღებულ მონაცემებს მუდმივად არ ინახავს.

## პროექტის გაშვება

პროექტის საქაღალდეში გახსენი ტერმინალი და გაუშვი:

```bash
npm install
npm run dev
